# Dashboard Finances

Application web de gestion de finances personnelles.

## Lien du site

https://dashboard-finances.onrender.com

## Technologies utilisees

- Python (Flask)
- HTML / CSS / JavaScript
- SQLite (base de donnees)
- Chart.js (graphiques)

## Fonctionnalites

- Tableau de bord avec solde, revenus et depenses
- Graphique des depenses par categorie
- Ajouter, modifier et supprimer des transactions
- Mode sombre / mode clair
- Donnees sauvegardees en base de donnees
